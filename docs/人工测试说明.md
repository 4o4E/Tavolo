# 人工测试说明

人工测试用于生成图片或动图，结果需要开发者人工查看。可自动断言的用例应优先放到 `src/test`。

## 命名规则

- 人工测试类统一使用 `*ManualTest` 后缀。
- 公共辅助类使用 `*ManualTestSupport` 后缀，避免被误认为普通业务类。
- 文件名与主要测试类名保持一致；一个文件内可包含少量强相关的人工测试类。

## 输出目录

人工测试工作目录为仓库根目录下的 `run`。

image-commands 模块的 handler 和 generator 输出统一写入：

```text
run/out/manual/image-commands
```

文件名使用类型和输入区分：

- `generator-<GeneratorName>.png`
- `generator-<GeneratorName>.gif`
- `handler-<HandlerName>-<InputName>-<InputExt>.png`
- `handler-<HandlerName>-<InputName>-<InputExt>.gif`

graphics 模块继续按功能输出到 `run/out/compose`、`run/out/render3d` 等目录。

## 运行方式

运行全部人工测试：

```shell
./gradlew manualTest
```

运行单个模块：

```shell
./gradlew :image-commands:manualTest
./gradlew :graphics:manualTest
```

运行单个类：

```shell
./gradlew :image-commands:manualTest --tests "*BasicImageHandlerManualTest"
./gradlew :graphics:manualTest --tests "*ComposeThemeManualTest"
```

文本字体 fallback 与 grapheme cluster 相关人工测试：

```shell
./gradlew :graphics:manualTest --tests "*ComposeTextFallbackManualTest"
```

这组测试需要准备 `run/font/FreeMono.ttf`。缺少字体时测试会跳过，准备后会输出：

- `run/out/compose/文本-fallback-01-grapheme-cluster-综合.png`
- `run/out/compose/文本-fallback-02-换行省略和行内样式.png`
- `run/out/compose/文本-fallback-03-字体候选和混排边界.png`

人工检查重点是组合圈是否贴在基字上、emoji ZWJ 与国旗是否未被拆开、ellipsis 是否保留完整 cluster、普通中文和英文是否仍保持主字体风格。

项目默认开启并行执行，配置位于仓库根目录的 `gradle.properties`：

```properties
manualTest.parallel=true
manualTest.maxParallelForks=4
```

临时关闭并行：

```shell
./gradlew manualTest -PmanualTest.parallel=false
```

指定并行 fork 数：

```shell
./gradlew manualTest -PmanualTest.parallel=true -PmanualTest.maxParallelForks=4
```

并行开启后，测试不得清空共享输出目录，不同测试应通过文件名区分输出。

## 圆角环形图

```shell
./gradlew :graphics:manualTest --tests "*ComposeRoundedDonutManualTest"
```

此入口使用真实 Skia 渲染及现有 `donutChart` 组件，生成：

| 文件（位于 `run/out/compose/`） | 检查内容 |
| --- | --- |
| `圆角Donut-01-原始快照-浅色.png` | 五组 WakaTime 快照，浅色背景 |
| `圆角Donut-02-原始快照-深色.png` | 相同数据和扇区颜色，深色背景 |
| `圆角Donut-03-原始快照-透明背景.png` | 透明圆心和扇区间距，可叠放在其他背景上检查 |
| `圆角Donut-04-四倍几何放大.png` | 内外主圆弧、四角相切和窄扇区两端的最大可用圆角 |
| `圆角Donut-05-几何边界.png` | 满圆、半圆、大扇区、近满圆、跨零角、极小值、空数据、薄厚环、独立关闭圆角／间距、描边，以及实心饼图的大扇区和近满圆 |
| `圆角Donut-06-样式选择.png` | 五组数据的圆角／间距四种开关组合，环厚固定，每个圆环区域均为 140×140 |
| `圆角Donut-07-AI-Models-样式放大.png` | 四种开关组合下 AI Models 的四倍几何放大，检查六个份额 |

前三张图中每个图表组件为 340×166 像素，包含右侧图例；圆环外径为 130 像素，外半径 65、内半径 36、圆角半径 4、间距 3，无描边。样图06的每个图表单元为 140×140 像素，不包含图例。放大图将圆环几何尺寸放大四倍，图例保持常规字体大小。深色背景使用 `#0D1117`；三种背景均使用人工入口传入的同一组固定配色，不由图表组件替换颜色。

数据来源为 [issue #1](https://github.com/4o4E/Tavolo/issues/1) 给出的 Languages、Editors、Operating Systems、Categories、AI Models 公开快照。图例显示输入百分数，不以几何归一化后的比例替换显示值。AI Models 的 0.85%、0.63%、0.67% 及 Unknown OS 0.04%、Building 0.01% 均保留原始图例数值。极小份额的内外圆角分别取各自空间允许的最大半径，允许同一端的两个圆角相接；实际尺寸下的弧长可能低于像素分辨率。

开关组合如下；外半径均为 65，内半径均为 36，数据、颜色和其他参数保持相同。先预留固定间距，再按输入占比分配未倒圆角的内圆弧。圆角开关不改变扇区起止角度和分配宽度；圆角只裁切扇区边角，不为圆角额外扩大扇区。四种组合均使用相同的统计数值。

| 组合 | 圆角半径 | 固定间距 |
| --- | --- | --- |
| A · 圆角关闭 · 间距关闭 | 0 | 0 |
| B · 圆角开启 · 间距关闭 | 4 | 0 |
| C · 圆角关闭 · 间距开启 | 0 | 3 |
| D · 圆角开启 · 间距开启 | 4 | 3 |

自动回归入口：

```shell
./gradlew :graphics:test --tests "*ComposePieArcProportionTest" --tests "*ComposeRoundedDonutTest" --tests "*ComposeCanvasAndChartUnitTest"
```

回归包含四角裁切与相切连续性、同心主圆弧、固定等宽间距、描边不填充间距、满圆无接缝、受限路径边界与自交检查，以及极小值标签／图例和默认饼图／环形图行为。四种开关组合均检查 AI Models 六个份额的实际尺寸可见像素；同时验证有／无描边时圆角开关控制尖角、间距开关控制侧边透明区域，圆心和扇区填充色保持正常。

圆角回归从组件实际绘制的原生路径切线重建圆角圆心和半径：20%、2%、0.63%、0.04%、0.01% 份额覆盖有／无间距，分别验证内外圆角达到各自允许的最大半径。空间足够时保留两个独立圆角，空间不足时两个圆角相接；关闭圆角时不产生内外圆角。测量路径同时交给真实 Skia 绘制。另在内半径 1／14／60／64.5、外半径65的半圆上测量超大圆角，验证实际半径达到环厚的一半，且同时与内外圆相切。

`ComposePieArcProportionTest` 从实际 Skia 路径中的圆弧端点、控制点及方向测量未倒圆角的内圆弧，不复用布局公式作为测量结果；同时识别极小圆弧的有理二次曲线和普通二次曲线表示。五组快照分别覆盖内半径 14／36／60、圆角 0／4／100、间距 0／3／10，共 135 组参数组合，分别在原点和实际绘图位置验证：未倒圆角的内圆弧非零且比例正确，圆角路径仍保留扇区中部填充，边界始终位于原始扇区及同心环带内。原点比例的绝对误差容限为 `2e-7`（0.00002 个百分点）；平移后的容限按实际 Float 坐标的 ULP 换算，并计入弧长归一化的误差传播。

圆角开启时，还从实际路径的直线和圆弧端点切线检查两条侧边的角度与固定偏移，保证边界不因圆角而扩张或收缩。接触点必须位于对应的径向射线，避免半圆的共线侧边被重复计为同一端；实际组件同时覆盖50%／50%和AI Models数据。圆角达到半环厚、直线侧边退化成切点时同样验证。不能容纳间距的直接路径用例明确断言为空，其余受限用例必须具有可测量边界，再检查范围与自交。

实心饼图另外覆盖五组快照、圆角 0／4／100、间距 0／3／30，共 45 组中线比例回归。固定间距回归在保留直线侧边的配置下测量全部相邻边界（包括首尾边界），配置 3 像素时各处误差容限为 0.0001 像素，包含 0.04% 和 0.01% 份额。另验证间距占满内圆周时明确拒绝，实际组件在圆角 0／4／100 下均保持相同扇区分配和标签引线位置，以及 100% 数据项保留完整圆环。
