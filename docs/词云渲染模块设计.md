# 词云渲染模块设计

## 目标

`:word-cloud` 是 Tavolo 的可选词云渲染模块，负责把已经聚合好的词频列表渲染为图片。

模块只处理平台无关的图片生成能力：

- 词频列表到词云布局。
- Skiko 图片渲染。
- 模板图片到二值蒙版。
- OTSU 阈值二值化。
- Sobel 边缘检测。
- 人工测试图片输出。

模块不处理业务统计能力：

- 文本采集。
- 分词。
- 词频存储。
- 权限和命令交互。
- 敏感词、隐私过滤和数据保留策略。

## 模块边界

新增 Gradle 模块：

```text
:word-cloud
```

发布坐标：

```kotlin
implementation("top.e404.tavolo:tavolo-word-cloud:<version>")
```

不放入 `:core` 或 `:graphics`：

- `:core` 面向指令资源、表情处理和输入驱动生成器，词云不是指令运行时的必需能力。
- `:graphics` 面向 Compose 绘图 DSL 和通用图表，词云布局有独立算法和测试策略。
- `:word-cloud` 保持可选依赖，避免所有使用者被动引入词云渲染能力。

## 技术路线

词云模块统一使用 Skiko，不引入 AWT 和 Kumo。

选择 Skiko 的原因：

- Tavolo 现有图像渲染主链路已经基于 Skiko。
- 字体解析可以复用 `FontManager`。
- 服务端不需要额外处理 AWT headless 场景。
- 输出类型可以直接使用 Skiko `Image`，也可以编码为 PNG 字节。

第一版布局使用轻量自研算法：

1. 清洗词频：过滤空文本和非正权重。
2. 按权重降序截断到 `maxWords`。
3. 使用平方根比例映射字号，避免高频词过度压制中频词。
4. 从画布中心和随机可绘制锚点沿螺旋线尝试放置。
5. 使用旋转后的文字实际像素做碰撞检测，透明外接区域不占位。
6. 使用文字实际像素检查蒙版约束，文字本身必须落在可绘制区域。
7. 生成 `WordCloudPlacedEntry` 后交给 Skiko 绘制。

当前布局已经使用像素级文字占用，密度和模板边界贴合度高于矩形外接框方案；旋转文本会先生成旋转后的像素占用，再参与蒙版和碰撞检查。代价是大画布、大词量人工测试会更慢。

## API 设计

包名：

```kotlin
package top.e404.tavolo.wordcloud
```

核心数据结构：

```kotlin
data class WordCloudEntry(
    val text: String,
    val weight: Int,
)

data class WordCloudOptions(
    val width: Int = 1600,
    val height: Int = 1200,
    val fontFamily: String = TavoloFonts.MI,
    val minFontSize: Float = 18f,
    val maxFontSize: Float = 180f,
    val padding: Int = 2,
    val backgroundColor: Int = 0xFFDDDDDD.toInt(),
    val maxWords: Int = 500,
    val spiralStep: Float = 6f,
    val angleStep: Float = 0.38f,
    val maxPlacementAttempts: Int = 2800,
    val randomSeed: Long = 404L,
)
```

渲染入口：

```kotlin
object TavoloWordCloud {
    fun render(
        entries: List<WordCloudEntry>,
        options: WordCloudOptions = WordCloudOptions(),
    ): Image

    fun render(
        entries: List<WordCloudEntry>,
        mask: WordCloudMask,
        options: WordCloudOptions = WordCloudOptions(width = mask.width, height = mask.height),
    ): Image

    fun renderPng(
        entries: List<WordCloudEntry>,
        mask: WordCloudMask? = null,
        options: WordCloudOptions = WordCloudOptions(),
    ): ByteArray
}
```

模板蒙版入口：

```kotlin
object WordCloudMaskFactory {
    fun resizeByMaxSide(image: Image, maxSide: Int): Image
    fun fromOtsu(image: Image, options: OtsuMaskOptions = OtsuMaskOptions()): WordCloudMask
    fun fromEdges(image: Image, options: EdgeMaskOptions = EdgeMaskOptions()): WordCloudMask
    fun otsuThreshold(values: IntArray): Int
}
```

## 模板策略

### OTSU 二值化

`fromOtsu()` 适合黑白模板、明暗对比清晰的图标和剪影。

默认规则：

- 深色像素作为可绘制区域。
- 透明像素忽略。
- 输入图最大边默认缩放到 1000，避免逐像素处理过慢。

### 边缘蒙版

`fromEdges(fillBetweenEdges = false)` 使用 Sobel 边缘检测，只保留边缘线。

该策略适合观察轮廓，不适合直接放大量词，因为可绘制区域很薄。

`fromEdges(fillBetweenEdges = true)` 会把边缘作为边界，按轮廓层级交替填充边缘之间的区域。

边缘填充不按扫描段切条。实现上先把非边缘区域分成连通域，再用边缘组件建立相邻区域关系，从画布外部区域开始计算跨边缘深度；奇数层区域填充，偶数层区域保留空白。它依赖边缘是否闭合；真实图片边缘断裂时，可以调大 `dilateRadius`，但值过大会吞掉细节。

## 测试计划

单元测试：

- 空词频列表抛出明确异常。
- 空文本和非正权重被过滤。
- OTSU 阈值对黑白像素返回稳定结果。
- OTSU 蒙版能正确区分深色区域和浅色背景。
- 纯边缘蒙版能生成非空边缘。
- 边缘填充能把闭合边缘内部整体变为可绘制区域。
- 有模板渲染输出尺寸等于模板蒙版尺寸。

人工测试：

- 矩形词云。
- 使用固定尺寸大画布渲染单个加粗数字作为模板图。
- 使用大量短词、长词和明显权重差异，检查大词、中词和长尾词在密集场景下的可读性。
- 在同一张左右对应的对比图中展示原图、OTSU、纯边缘、边缘填充和对应词云。
- 输出到 `run/out/manual/word-cloud`，人工检查模板边界、内洞保留、字体清晰度和词语密度。

运行：

```shell
./gradlew :word-cloud:test
./gradlew :word-cloud:manualTest
```

## 后续优化

- 支持按词条特征选择旋转角度，例如短词少量竖排、长词保持横排。
- 缓存相同词条和字号的文字像素数据，降低大词量人工测试耗时。
- 增加更稳定的边缘闭合预处理，例如轮廓追踪、连通域分析或形态学闭运算。
- 为 HTTP 服务增加可选路由，但不影响本地 API。
